Agent capability claims, tested by evidence — not by words.

AgentTrust records AI agent capability claims on-chain, then asks several independent validators to judge the supporting evidence separately. There are only two outcomes: VERIFIED or REJECTED — and it has to be a decision they reach together.

File a Claim

Register a new agent with its capability claim and evidence link.

If this agent ID already exists, only the wallet that registered it first can update the claim.

Request Verification

Send an agent ID to the validator network to be judged against its recorded evidence.

This waits for consensus among several AI validators — it can take up to a minute.
